# Product upgrades — 2026-10-18

## Entry points

Today keeps all three actions: **Tell Tempo more**, **Replan from now**, and **My day changed**. The quick replan saves immediately; My day changed provides availability controls and a review before saving. Today also links to weekly planning and the inbox. Settings → Tools links to every added screen.

- **Capture and tasks:** optional deadline dates and low/normal/high priority survive cloud storage. AI extraction names projects and clarifies ambiguities in review notes. Matching project names are selected automatically; unknown projects can be created in the existing picker. The local fallback handles explicit dates, today/tomorrow, weekdays, priority words, and `for project …`. Captured estimates and metadata stay editable before saving.
- **Next step:** Start persists a focus start time, Done advances the day, Snooze looks for a free slot after ten minutes while preserving appointments, and “I’m stuck” lets the user save a small first step. Snooze reports when no slot fits. The separate `/next` screen provides the same focused experience.
- **Weekly planning:** select flexible work, review a seven-day schedule, and save atomically. Deadlines and priority determine order. Fixed/completed tasks remain unchanged; recurring occurrences keep their dates. Unfittable work remains waiting. Accepted project members’ explicitly saved busy windows block that project’s tasks; private work can use those windows. Recheck availability and workspace revision before saving.
- **Shared projects:** owners invite existing Tempo accounts. Acceptance reveals project tasks and comments; owners assign work and manage members. Accepted members can comment and update completion. Removal revokes access and clears assignments. Existing task-level sharing remains independent.
- **Comments and inbox:** own task editors and shared project tasks expose comments. Invitations, comments, assignments, and shared-task changes produce durable inbox records even without a registered push device. The inbox adds approaching/overdue task deadlines and supports marking updates read.
- **Search, undo, sync, accessibility:** task search matches titles, project names, steps, and deadlines. Successful workspace edits expose one safe Undo action, guarded by the saved revision. Deletions and collaboration permission changes are excluded from undo; restoring task data would not restore deleted comments or invitations. Cloud save/error state is visible. Buttons wrap labels, scale with system text, and retain at least 44-point compact targets.
- **Calendar:** rebuilt iOS/Android apps request device-calendar access on demand. Users choose a calendar, review the coming week, and select appointments to import. Imported appointments are fixed; repeat imports skip existing identities. This is snapshot import, not continuous calendar sync. All-day and over-24-hour events are excluded. Writable calendars expose the system event confirmation form for exports. Web downloads an `.ics` file; native also supports sharing calendar text.
- **Widget:** the iOS home/lock-screen Tempo Next widget displays the next planned task after an explicit task-title opt-in. Opening/updating Tempo refreshes it; signing out clears its task content. A one-day expiry replaces stale content with a refresh prompt. Android and web retain the focused next-task screen; native Android widgets are not included.
- **Password recovery:** sign-in exposes Forgot password, email code request, and password replacement. Codes are hashed, expire after 30 minutes, are single-use, and revoke sessions/push registrations when used. Requests return a generic message for existing/non-existing accounts. The server needs `RESEND_API_KEY` and `TEMPO_MAIL_FROM` with a verified sender to send email. No live recovery email was sent during testing.

Integration tests use isolated schemas and clean them afterward.

Native compile status is recorded after its build attempt.
